  report. All overlaps were in TASKS.md; both existing publication records and
  the World/research ownership rows were retained.

  persistence. A rejected URL update no longer prevents the saved workspace
  or submitted simulation from opening. Regression tests cover both paths.

  of bounded activity history, for modern and legacy approvals. Old snapshots
  without recorded metadata show an unknown state rather than invented review.

  a Library connection change. Changing, adding or removing only reportId
  preserves local approval, review, prose, reasoning and retained versions.
  The link receives a new local revision and history entry; repeating the same
  link has no effect. Incoming review metadata cannot replace the local review.
- Material import changes still clear current approval, retain the previous
  version and update draft, sources and reasoning in the same transaction.
  Existing stale-revision and all-or-nothing batch protections remain active.
