# WEB-019: Workspace recovery and local folder backups

Codex author QA under the owner's temporary takeover authorization in
AI_COLLABORATION.md. No independent Claude review is claimed.

## Behavior

A missing project deep link leaves saved projects untouched, removes the stale
project parameter and opens the queue, new-project form, import and export tools.
Valid project links keep selecting their requested record. Storage errors retain
an explicit error instead of inventing project records.

Folder backup is opt-in on localhost. The existing browser settings store keeps
the directory handle separately from portable research records. Committed
Workspace and World mutations schedule a backup after one second. Opening or
refocusing either page checks for missed changes. No network upload is added.
Chrome/Edge's native folder picker requires a user selection; no folder access
was pre-granted on the owner's behalf. Manual JSON exports remain available.

The writer uses a fresh dated snapshot folder. Every numbered project file stays
within the existing 5 MB import limit; snapshot.json is written last as the
completion marker. Old snapshots are never removed or overwritten. Failures,
permission loss, pending writes and successful backups have separate visible
states. Research saves survive backup errors. Browser Web Locks serialize folder
writes across tabs where available. Unsaved text and PDFs are not included.
