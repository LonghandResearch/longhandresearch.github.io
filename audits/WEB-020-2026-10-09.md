# WEB-020: Folder picker feedback

The owner reported that the folder-selection confirmation did not appear. Clicking
Choose backup folder in the current in-app browser left the status unchanged.
The updated preview reports an aborted selection, with no console errors.
Native folder selection and automatic folder writes remain unverified in this browser.

Changes:
- Show guidance immediately while the native picker is pending.
- Explain cancelled selections without changing an existing backup configuration.
- Prevent duplicate pickers and focus checks from replacing the pending guidance.
- Explain JSON export/import before switching browsers, whose stores are separate.
- Disable Back up now until a folder is configured.

Validation: site check (49 scripts, 67 JSON files, 11 catalogue entries, 16 pages);
node --check; ten backup regression tests; browser preview of the
cancelled picker message and retained controls. The owner's current localhost
workspace was exported through Export backup; its JSON format and the local copy
hash were checked. No projects were edited, imported or deleted. The JSON was
saved outside the repository and is not committed.

Codex author QA under the owner's temporary takeover authorization in
AI_COLLABORATION.md. Independent Claude review was unavailable.
