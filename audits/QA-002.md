## Figures derived on the page

Recomputed from the data file; each agrees with the text.

| Figure | Recomputed |
| --- | --- |
| Weekly IHSG return | (6,241.892 ÷ 6,441.159 − 1) = −3.09% |
| Sum of daily foreign flow | −3,155.08, equal to the weekly figure |
| Three-week net selling | Rp9.46tn (−9,462.62bn) |
| Thursday's share of the week's net selling | 47.3% |
| Wednesday's gain erased by Friday | 97.868 pts gained, 133.020 lost: 135.92% |
| Market cap decline | Rp361tn |
| Turnover per share, week on week | Rp532.05 to Rp410.24: −22.89% |
| JISDOR change between Fridays | +0.97% |
| Indicative unhedged USD return | (1 − 0.0309) ÷ (1 + 0.0097) − 1 = −4.02% |
| Venue values | Sum to the weekly total exactly |

One rounding note, not an error: the displayed average daily trade counts
(1,892 and 1,817 thousand) give −3.96%, while IDX reports −3.95% from exact
totals. The page shows IDX's −3.95% and says ratio changes use exact weekly
totals.
